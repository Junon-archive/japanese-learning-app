# Product Vision

## 한 줄 정의

사용자의 일본어 수준을 지속적으로 추정하고, 이해 가능한 일본어 문맥을
제공하며, 모르는 단어·문법·표현을 문맥 기반 SRS로 자연스럽게 습득시키는
개인화 일본어 학습 앱.

## 목표

-   일본어 YouTube의 일상 콘텐츠를 상당 부분 이해
-   일본인과 일상 주제로 대화
-   한자는 handwriting이 아니라 recognition/reading 중심
-   연구가 바쁜 날에도 낮은 마찰로 습관 유지

우선순위: `이해/청해 > 어휘·문법 인식 > 회화 > 읽기 >>> 한자 손글씨`

Core Loop:
`Sentence → 표현 확인 → 설명 → 학습 신호 → SRS → 다른 문맥 재노출`

장기 Content Source: LLM-generated / YouTube / Manual text / 기타 실제
일본어.
