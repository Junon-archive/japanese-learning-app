# Product Vision

## 한 줄 정의

사용자의 일본어 수준을 지속적으로 추정하고, 이해 가능한 일본어 문맥을
제공하며, 모르는 단어·문법·표현을 **문맥 기반 SRS**로 자연스럽게
습득시키는 개인화 일본어 학습 앱.

## 사용자 목표

주 사용자는 일본어 초급자이며 한자 지식과 문장 생성 능력이 낮다. 목표는
시험 자격증이 아니라 약 1년 동안의 꾸준한 사용을 통해 다음에 가까워지는
것이다.

-   일본어 YouTube의 일상적 콘텐츠를 상당 부분 이해한다.
-   일본인과 일상적인 주제로 자연스럽게 대화를 이어간다.
-   한자를 손으로 쓰는 능력은 목표로 하지 않는다.
-   연구·업무가 바쁜 날에도 매우 낮은 마찰로 학습을 유지한다.

## 능력 우선순위

`이해/청해 > 어휘·문법 인식 > 회화 > 읽기 >>> 한자 손글씨`

## 제품의 장기 모습

콘텐츠는 하나의 공급원에 종속되지 않는다.

-   LLM-generated content
-   YouTube-derived content
-   사용자가 직접 넣은 일본어
-   기타 실제 일본어 자료

모든 콘텐츠는 공통 Sentence Pool과 Learning Engine을 거쳐 개인화된다.

## 성공의 핵심

이 제품의 성공은 기능 수가 아니라 다음 Core Loop가 실제로 매일 사용될
정도로 편하고 유용한지에 달려 있다.

`Sentence → 모르는 표현 확인 → 설명 → 학습 신호 → SRS → 다른 문맥에서 재노출`
