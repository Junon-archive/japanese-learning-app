표현 설명

문장 안의 표현을 누르면 읽기, 핵심 의미, 현재 문맥에서의 뜻과 짧은 예문이 표시됩니다.
なんとなく
nantonaku
expression
왠지 / 특별한 이유 없이

뚜렷한 이유를 설명하기 어렵지만 어떤 느낌이나 상태가 있을 때 자연스럽게 씁니다.

이 문장에서는: “특별한 이유는 없지만 왠지”라는 느낌입니다.

なんとなく今日は家にいたい。
気が乗らない
き が のらない
expression
내키지 않다 / 할 마음이 나지 않다

해야 할 이유는 있어도 기분이나 의욕이 따라주지 않을 때 자주 사용하는 일상 표현입니다.

이 문장에서는: 연구실에 갈 생각이었지만 마음이 내키지 않았다는 뜻입니다.

今日はあまり出かける気が乗らない。
가끔 앱이 먼저 확인합니다

클릭하지 않았다고 해서 “안다”고 판단하지 않습니다. 일부 표현은 짧게 확인해 실제 이해도를 추정합니다.
