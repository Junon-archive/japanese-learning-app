# Learning Policy

## Mastery

`comprehension`, `listening` 2축.

## Signals

강한 신호: explicit known/uncertain/unknown, probe 정오답, review
result.\
보조 신호: click, explanation reveal, translation reveal, audio replay.\
no-click/page view는 중립 또는 매우 약한 신호.

## Active Probe

사용자가 unknown-unknown을 가질 수 있으므로 앱이 먼저 확인한다. 12분
세션당 초기 목표 약 2\~4회 이하, configurable. `안다/애매/모름/skip`
또는 간단 객관식 가능.

## Novelty

신규 item 권장 1, 최대 2.

## Mix

Review 70 / New 20 / Exploration 10. backlog가 많으면 review↑ new↓.

## Exposure

최소 meaningful exposure 5회. 5회는 졸업 조건이 아님. 초기
원문/near-original → 약간 다른 문맥 → 새로운 일상 문맥 → 가능하면
listening.

## Topic

개인화하되 특정 관심사 과적합 금지.
