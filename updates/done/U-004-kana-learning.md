-   방문자가 선택 홈에서 "글자부터 배우기"를 고를 수 있어야 한다(`U-001`).
-   프론트엔드만으로 동작하는 히라가나·가타카나 학습을 추가한다.

## 2. 원하는 것 --- 사용자 결정 (2026-09-13)

### 격리 수준

demo와 같다. 서버 요청 0건, API 모듈 import 금지. route는 `#/kana` 계열이다.

### 범위: 히라가나와 가타카나 각각

-   청음
-   탁음
-   반탁음
-   요음
-   촉음(っ/ッ)
-   장음(히라가나 모음 연장, 가타카나 `ー`)
-   외래어
    -   가타카나 단어 예시와 한국어 뜻
    -   외래어용 확장 표기(ティ, ファ 등) 포함

### 퀴즈 방식은 두 가지뿐이다

-   **보고 읽기:** 글자나 단어를 보여준다 → [정답 보기] → 사용자가 맞음/틀림을 스스로 표시한다.
-   **보고 고르기:** 글자를 보고 4지선다로 고른다.
-   촉음·장음·외래어는 단어 단위로 묻는다.

### 정답 표기

로마자(헵번식)를 기본으로 하고, 한글 발음을 보조로 함께 표시한다.

### 진도 저장

-   저장 위치는 localStorage다. 모든 접근을 try/catch로 감싼다.
-   저장이 불가능해도 정상 동작해야 한다.
-   저장하는 것: 글자별 맞음/틀림 수, 마지막 학습 시각
-   진도 초기화 버튼을 둔다.
-   스케줄링은 "틀린 것을 같은 라운드에서 한 번 더 묻기"까지만 한다.

### 데이터 품질

-   정적 데이터에는 표 전체와 외래어 약 30개가 들어간다.
-   개수, 중복, 로마자 형식, 한글 표기 누락을 unit test로 검사한다.

### 불변식 (MVP-02 추가 불변식 13·16·18)

-   13\. 홈·demo·가나 학습은 서버 요청 0건이다. API 모듈을 import하지 않는다.
-   16\. 후리가나 표시·토글, 가나 학습, demo 진행은 학습 이벤트·exposure·evidence를 만들지 않는다.
-   18\. localStorage는 후리가나 설정, 가나 진도, demo 진도에만 쓴다. secret이나 서버 데이터를 넣지
    않는다. 저장이 없어도 정상 동작한다.

## 3. 원하지 않는 것 --- 사용자 결정 (2026-09-13)

-   소리·획순은 제외한다.
-   SRS/FSRS를 쓰지 않는다. 가나 SRS는 범위 밖이다.
-   가나 진도를 서버로 보내지 않는다(계정 동기화는 범위 밖).
-   불확실한 외래어는 넣지 않는다.
-   프론트엔드 의존성을 추가하지 않는다.

## 4. 참고 --- 사용자 결정 (2026-09-13)

## 5. 완료 확인 방법 --- 사용자 결정 (2026-09-13)

-   가나 학습 route가 서버 요청 0건이고 API 모듈을 import하지 않는다.
-   히라가나와 가타카나 각각 위 범위를 모두 담는다.
-   퀴즈는 보고 읽기와 보고 고르기 두 가지이고, 촉음·장음·외래어는 단어 단위로 묻는다.
-   localStorage 저장이 불가능해도 정상 동작한다.
-   진도 초기화 버튼이 있다.
-   정적 데이터의 개수, 중복, 로마자 형식, 한글 표기 누락을 unit test로 검사한다.

정식 합격 기준은 Wave 1의 `spec/mvp-02-onboarding/13_ACCEPTANCE_CRITERIA.md`다.
